Claude Code を使い始めたとき、僕がわからなかったことは5つありました。

- 普通の Claude（チャット）と何が違うのか
- 何が、どのくらいのレベルでできるのか
- どのモデルを選べばいいのか
- 利用制限をすぐ使い切ってしまうのはなぜか
- そもそも ChatGPT や Copilot と比べて、どれがいいのか

今は、このブログのサイトづくりも、YouTube の動画づくりも、Claude Code で進めています。iPhone のホーム画面で使うアプリも作りました。上の5つに答えながら、Windows で使い始める手順を書きます。

<Box type="point" title="先に結論">
- Claude Code は「チャットで答える AI」ではなく、**パソコンの中で手を動かす AI**です。ファイルを読み書きし、コマンドを実行します
- 使うには有料プランが必要です。最初は **Pro（月20ドル。年払いなら月17ドル）** で十分
- Windows なら、ターミナルを使わずに済む **Claude のデスクトップアプリ**から始めるのがラク
- モデルは、最初は初期設定（Opus 5.5）のままでいい。制限が気になったら Sonnet に切り替える
- 利用制限は **チャットと Claude Code で共通**。作業ごとに `/clear` で会話を区切るだけでも、減り方が変わります
</Box>

料金は2026年11月7日、モデルの情報は11月5日に公式サイトで確かめたものです。よく変わるので、申し込む前に公式サイトも見てください。

## Claude Code と普通の Claude の違い

いちばん大きな違いは、**AI が自分で手を動かすかどうか**です。

普通の Claude（claude.ai やスマホのアプリ）は、質問に答えます。文章やコードを書いて見せることもあります。書いたコードを保存して動かすのは、自分の仕事です。

Claude Code は、パソコンの中のフォルダを開いて作業します。公式の説明では「コードを読み、ファイルを編集し、コマンドを実行する」道具です。たとえば「このフォルダにブログを作って」と頼むとします。すると、必要なファイルを作って部品を入れ、表示の確認まで進めます。

| | 普通の Claude（チャット） | Claude Code |
| --- | --- | --- |
| すること | 答える・書いて見せる | ファイルを作る・直す・コマンドを動かす |
| 作業する場所 | 会話の画面の中 | 自分のパソコンのフォルダ |
| 向いていること | 調べもの、文章の相談、考えの整理 | アプリやサイトづくり、作業の自動化 |
| 無料プラン | 使える | 使えない（Pro 以上） |

もう一つ、最初に知っておきたいことがあります。Claude Code は、ファイルを書き換える前やコマンドを動かす前に、許可を求めてきます。何をするかが表示されます。読んでから許可すれば、勝手にファイルを消される心配はほとんどありません。

## 何が、どのくらいのレベルでできるのか

僕が実際に Claude Code で作ったものを挙げます。

- **このブログ**：デザイン、記事の一覧、目次、プライバシーポリシーのページ、GitHub Pages への公開の設定まで
- **YouTube の解説動画**：テーマを1行渡すと、台本、ナレーション、映像、サムネイルまで作る仕組み
- **iPhone のホーム画面で使うアプリ**：1つの HTML で作って、GitHub Pages で公開

どれも、僕はプログラミングをほとんど書いていません。「こうしたい」を日本語で伝えて、出来上がったものを見て「ここを直して」と返す。その繰り返しです。

ただ、何でも一発でできるわけではありません。大まかに分けると、こうなります。

| レベル | 例 |
| --- | --- |
| 任せてほぼ大丈夫 | 小さなツール、1ページの Web ページ、文字やデザインの直し |
| 確認しながらならできる | ブログやアプリをまるごと作る、公開の設定まで進める |
| 人が決めないといけない | 何を作るか、デザインの好み、お金や個人情報が絡む操作 |

<Box type="memo" title="うまく頼むコツ">
「いい感じにして」では伝わりません。「スマホで見たとき、見出しが2行に折れないようにして」のように、**何がどうなれば完成か**まで書くと、やり直しが減ります。公式の説明でも、具体的に頼むことが勧められています。
</Box>

## 料金：無料では使えない

Claude Code は、無料プランでは使えません。Pro 以上の有料プランが必要です。

| プラン | 料金（月額） | Claude Code | 使える量の目安 |
| --- | --- | --- | --- |
| Free | 0ドル | 使えない | ― |
| Pro | 20ドル（年払いなら月17ドル。200ドルを一括） | 使える | 基準 |
| Max | 100ドル | 使える | Pro の5倍 |
| Ultra | 200ドル | 使える | Pro の10倍 |

（2026年11月10日、[Claude の料金ページ（日本語）](https://claude.com/ja/pricing)で確認。税は別）

Claude 以外のサービスも含めて、月額と年額の合計を出したいときは、[AI 有料プランの料金 計算ツール](/tools/ai-plan-cost/)が使えます。

最初は Pro で十分です。毎日何時間も使って、制限で止まるのが当たり前になってから、Max を考えれば間に合います。

## Windows での始め方

始め方は2通りあります。ターミナル（黒い画面）に慣れていないなら、①のデスクトップアプリがおすすめです。僕もふだんはこちらを使っています。

### 1. Pro プランに申し込む

[claude.ai](https://claude.ai) でアカウントを作り、Pro プランに申し込みます。Claude Code には、このアカウントでログインします。

### 2-①. デスクトップアプリで始める（ターミナル不要）

1. [Claude のダウンロードページ](https://claude.com/download)から、Windows 版をダウンロードして入れる
2. アプリを開いて、Claude のアカウントでログインする
3. 「Code」のタブを開き、作業するフォルダを選ぶ

デスクトップアプリには Claude Code が入っているので、別に入れる必要はありません。

### 2-②. ターミナルで始める

PowerShell を開いて、次のコマンドを貼り付けて実行します。管理者として開く必要はありません。

```powershell
irm https://claude.ai/install.ps1 | iex
```

入ったか確かめるには、次を実行します。版の番号が出れば成功です。

```powershell
claude --version
```

作業したいフォルダに移動して `claude` と打ちます。ブラウザが開くので、Claude のアカウントでログインすれば準備完了です。

<Box type="warn" title="つまずきやすいところ">
- **`'irm' は認識されていません`と出る**：PowerShell ではなく、コマンドプロンプトで実行しています。PowerShell を開き直してください
- **API の料金がかかってしまう**：パソコンに `ANTHROPIC_API_KEY` という環境変数があると、プランではなく API の従量課金で動きます。心当たりがなければ気にしなくて大丈夫です
- **Git for Windows は入れておくと安心**：なくても動きますが、入っていると Claude Code がより多くのコマンドを使えます
</Box>

動く環境は、Windows 10（1809以降）か Windows 11、メモリ4GB以上です。

### 3. 最初に頼んでみること

いきなり大きなものを頼むより、結果がすぐ見えるものから始めると、感覚がつかめます。

- 「このフォルダの中身を説明して」
- 「今日の日付と、やることを入れられる1ページの ToDo リストを HTML で作って」
- 「Downloads フォルダの PDF を、ファイル名の日付ごとにフォルダ分けして」

## どのモデルを選べばいいのか

Claude には、性能と速さの違うモデルがいくつかあります。2026年11月時点の主なモデルはこの4つです。

| モデル | 向いていること | 速さ |
| --- | --- | --- |
| Fable 5.1 | いちばん難しい問題、長時間の作業 | 遅い |
| Opus 5.5 | ふだんの開発の中心。アプリづくりなど | ふつう |
| Sonnet 5.5 | 速さと賢さのバランス。日々のちょっとした作業 | 速い |
| Haiku 5.5 | 単純で量の多い作業 | いちばん速い |

Pro でも Max でも、Claude Code の初期設定は Opus 5.5 です。迷ったら、まずはそのままで使ってみてください。

切り替えるときは、Claude Code の中で `/model` と打ちます。一覧から選ぶか、`/model sonnet` のように名前で指定できます。

<Box type="point" title="使い分けの目安">
- 初期設定（Opus 5.5）：アプリやブログをまるごと作るとき
- Sonnet：文字の修正や小さな直しなど、やることがはっきりしているとき
- 利用制限が残り少ないときは、Sonnet に切り替える手もあります
</Box>

`/effort` で「どのくらい考えてから答えるか」も変えられます。公式の目安は3段階です。ちょっとした名前の変更なら low。ふだんの作業なら medium。バグの修正や、確認が大事な作業なら high です。考える量を増やすほど、使う量も増えます。

## 利用制限をすぐ使い切ってしまう理由と対策

これが、僕がいちばん困ったところです。制限の仕組みを知ると、減り方の理由が見えてきます。

### 制限の仕組み

- Pro と Max には、**5時間ごとの上限**と**1週間の上限**の2つがあります
- この上限は、**普通の Claude のチャットと Claude Code で共通**です。チャットでたくさん話した日は、Claude Code で使える分も減っています
- 残りは、Claude Code の中で `/usage` と打つと確かめられます

### 減り方を抑えるコツ

公式の説明で勧められている方法を挙げます。

1. **作業が変わったら `/clear` で会話を区切る**。Claude Code は、それまでの会話をすべて読み直しながら答えます。会話が長いほど、1回の返事で使う量が増えます
2. **長くなった会話は `/compact` で要約する**。続きの作業をしたいけれど、会話が長くなりすぎたときに使います
3. **やることがはっきりした作業は Sonnet で**。公式でも「ほとんどのコーディング作業は Sonnet でこなせて、Opus より安い」と書かれています
4. **具体的に頼む**。「全体を良くして」は、AI がファイルを片っ端から読むことになります。「auth.ts のログイン処理に、入力チェックを足して」のように、場所と中身を指定します
5. **大きな作業の前は、プランモードで計画を立てる**。Shift＋Tab で切り替えます。計画の段階でズレを直せば、作ってからやり直すより使う量が少なく済みます
6. **CLAUDE.md（毎回読み込まれる指示のファイル）を短くする**。公式の目安は200行以内です

## ChatGPT・Copilot・Gemini と比べて、どれがいいのか

結論から言うと、**一番いい AI は、何に使うかで変わります**。2026年11月時点で、それぞれの立ち位置をまとめるとこうなります。

| サービス | 有料プラン（月額） | 手を動かす開発の道具 | 向いている人 |
| --- | --- | --- | --- |
| Claude | Pro 20ドル | Claude Code | アプリやサイトをまるごと作りたい人。日本語の文章も多く書く人 |
| ChatGPT | Plus 3,000円 | Codex（Plus に含まれる） | 画像づくりや音声の会話など、いろいろな用途に1つで済ませたい人 |
| GitHub Copilot | Pro 10ドル（無料プランあり） | Copilot のエージェント・CLI | VS Code などでコードを書きながら、補完してほしい人 |
| Gemini | Google AI Pro 2,900円 | Google Antigravity | Gmail や Google ドライブをよく使う人。保存容量も欲しい人 |

（Claude・ChatGPT・Gemini は2026年11月10日に各社の料金ページで確認。GitHub Copilot は11月5日の確認）

3つのサービスの合計は、[AI 有料プランの料金 計算ツール](/tools/ai-plan-cost/)で試せます。

Windows に最初から入っている「Microsoft Copilot」は、質問に答えるチャット用の AI です。ファイルを作って動かす Claude Code とは役割が違います。

どのサービスも、コードを書いて動かす道具を持つようになりました。できることの差は縮まっています。選ぶときは、次の3つで考えるのがおすすめです。

- **何を作りたいか**：アプリやサイトをまるごと作るなら Claude Code か Codex。書いているコードの補完なら Copilot
- **ふだん使っているサービス**：Google のサービス中心なら Gemini、VS Code 中心なら Copilot
- **まず1つに絞る**：複数に課金するより、1つを使い込んだほうが、頼み方のコツが早く身につきます

僕は今のところ Claude に絞って、このブログのサイトも、動画もアプリも Claude Code で作っています。

## 次にやること

1. claude.ai で Pro プランに申し込む
2. デスクトップアプリを入れて、「Code」のタブでフォルダを選ぶ
3. 「このフォルダの中身を説明して」と頼んでみる

ここまで10分もかかりません。まずは1つ、小さなものを作ってもらってください。
