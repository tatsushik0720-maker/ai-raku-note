月3,000円。大学生にとっては、バイト数時間ぶんの金額です。AI の有料プランは、主な3社がどれもこのあたりに並んでいます。全部に払えば月9,000円近く。さすがに続きません。

僕がいま払っているのは Claude Pro の1つだけです。ChatGPT Plus にも1〜2か月払いましたが、やめました。Gemini の有料プランは使ったことがありません。Gemini の部分は、公式の料金ページを読んで書いています。

<Box type="point" title="先に結論">
- 真ん中のプランは、Claude Pro が月20ドル、ChatGPT Plus が月3,000円、Google AI Pro が月2,900円。金額の差はほとんどない
- 差が出るのは「何がついてくるか」。Claude は Claude Code、ChatGPT は画像づくりと Codex、Google は5TBの保存容量と YouTube Premium Lite
- 学生向けの特典をはっきり書いていたのは Google だけ（AI Plus が1年間無料、AI Pro が最大70%オフ）
- 最初は1つに絞る。僕は ChatGPT Plus をやめて、アプリや動画の仕組みを作れる Claude Pro だけにした
</Box>

（料金と中身は、2026年11月12日に各社の公式の料金ページで確認しました。出どころは記事の最後にまとめています）

## 3社の料金を並べる

個人向けのプランを、安い順に並べました。

| | Claude | ChatGPT | Google AI（Gemini） |
| --- | --- | --- | --- |
| 無料 | Free | 無料版 | （有料プランなしでも使える） |
| 安いプラン | なし | Go 1,400円 | AI Plus 725円 |
| 真ん中 | Pro 20ドル（年払いなら月17ドル） | Plus 3,000円 | AI Pro 2,900円 |
| 上のプラン | Max 100ドル、Ultra 200ドル | Pro 16,800円から | AI Ultra 14,500円から |

金額はすべて月額です。Claude はドル表示です。ページの下に「表示価格には適用される税金が含まれていません」とあります。仮に1ドル150円とすると、Pro の20ドルは3,000円ほど。為替しだいで毎月少し動きます。

ChatGPT と Google は円の表示です。税込か税抜かの注記は、料金ページに見当たりませんでした。実際に払う額は、申し込みの画面で確かめてください。

Claude Pro の年払いは、200ドルを一度に払う形です。月払いより年40ドル安くなります。ただ、途中で別のサービスに移りたくなるかもしれません。最初の1〜2か月は月払いで様子を見るのが安全だと思います。

自分の組み合わせで月額と年額を出したいときは、[AI 有料プランの料金 計算ツール](/tools/ai-plan-cost/)が使えます。

## 真ん中のプランで、何がついてくるか

3,000円前後のプランどうしを、公式ページの説明で比べます。表に出てくる Claude Code・Codex・Antigravity は、文章で頼むとプログラムを書いて動かしてくれる道具です。

| | Claude Pro | ChatGPT Plus | Google AI Pro |
| --- | --- | --- | --- |
| コードを書いて動かす道具 | Claude Code | Codex（上限が広がる） | Google Antigravity（利用枠が広がる） |
| 調べものの機能 | Research | Deep Research の拡張 | Deep Research の利用枠が広がる |
| 画像・動画づくり | 料金ページに記載なし | より高度な画像生成 | 画像・音楽・動画の生成の利用枠が広がる |
| 保存容量 | なし | なし | 5TB（Gmail・ドライブ・フォト共通） |
| そのほか | Chrome や Microsoft 365 で使える | プロジェクト、カスタム GPT | YouTube Premium Lite、家族5人まで共有 |

こうして並べると、性格の違いが見えてきます。

- **Claude Pro**：無料プランでは使えない Claude Code がつく。アプリやサイトを作りたい人向け
- **ChatGPT Plus**：画像づくりも調べものもコードも、1つで広く使いたい人向け
- **Google AI Pro**：AI のほかに、5TBの保存容量と YouTube の特典がつく。Google のサービスをよく使う人向け

「どれが一番賢いか」は、モデルが新しくなるたびに入れ替わります。料金ページからは決められません。だから僕は、賢さではなく「自分の作業に要る道具がついているか」で選びました。

## 大学生が見ておきたい3つのこと

### 1. 学生向けの特典があるのは Google

Google の料金ページには、学生向けの特典が書いてありました。内容は2つです。AI Plus が1年間無料になること。AI Pro へ切り替えると最大70%オフになること。対象の条件と期間は、ページの「学生割引プラン」のリンクを開いて確かめてください。僕はこの特典を申し込んでいないので、手続きの流れは書けません。

Claude と ChatGPT の料金ページには、個人の学生向けの割引は載っていませんでした。ChatGPT には「ChatGPT Edu」という大学向けのプランがあります。ただ、これは大学がまとめて入るもので、学生が1人で申し込むものではありません。

### 2. 安いプランは、中身をよく見る

ChatGPT の Go（1,400円）には、「このプランには広告が表示される場合があります」と注記があります。高度な推論のモデルが使えるのは Plus からです。

Google の AI Plus（725円）は、保存容量が400GBで、Gemini の利用枠が2倍になります。AI Pro に書いてある Antigravity の利用枠の拡大や YouTube Premium Lite は、Plus の説明にはありません。

安さだけで決めると、やりたかったことができないかもしれません。申し込む前に、使いたい機能がそのプランに入っているかを見てください。

### 3. Claude Code を使うなら、Pro 以上が要る

Claude Code は、Claude の無料プランでは使えません。有料のプランすべてに含まれていて、一番安いのが Pro です。使える量の上限は、5時間ごとと1週間ごとの2つ。チャットと Claude Code は、同じ枠から減っていきます。

始め方は、[Claude Code の始め方【Windows】](/blog/claude-code-windows-start/)に書きました。

## ChatGPT Plus をやめて、Claude Pro だけにした理由

ChatGPT Plus は、レポートや勉強の調べものに使っていました。払ったのは1〜2か月です。

やめた理由は単純で、作りたいものができたからです。Claude Code でアプリや動画の仕組みを作りたくなりました。そうなると、調べものにもう3,000円を払い続ける理由がなくなったんです。

作ったものは3つあります。このブログのサイト、YouTube の解説動画を作る仕組み、iPhone のホーム画面に置くアプリです。どれも、プログラムは Claude Code で組みました。僕にとって有料プランは、チャットの相手というより、ものを作るための道具なんです。

もう1つの理由は、道具を1つに絞ったほうが上達が早いこと。頼み方のコツは、同じ道具を毎日さわるほうが早く身につきます。2つに払い続けていたら、どちらも中途半端だったと思います。

<Box type="memo" title="2つめを足すなら">
1つめで足りない作業がはっきりしてから、その作業だけ無料版で試すのがおすすめです。ChatGPT も Gemini も無料で始められます。無料で足りなくなってから、有料にするか考えれば間に合います。
</Box>
