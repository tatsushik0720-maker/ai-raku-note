「AI を使うなら、どんなノート PC を買えばいいのか」。同じ大学生から、こう聞かれたら答えたいと思って書きました。

先に言っておくと、僕は PC に詳しいわけではありません。いくつものノート PC を比べて買ったわけでもありません。手元にあるのは1台です。その1台で、Claude Code も、YouTube の動画づくりも、VOICEVOX も動かしてきました。この記事は、その1台で見えたことと、公式サイトで確かめた動作条件だけで書いています。メーカーごとの機種のおすすめは、僕には書けません。

<Box type="point" title="先に結論">
- チャットで AI を使うだけなら、ほとんどのノート PC で足ります。AI の処理は、パソコンの外のサーバーで動くからです
- Claude Code の公式の動作条件は、**メモリ4GB以上**・Windows 10（1809以降）など。軽いほうです
- 差が出るのは、動画の書き出しのような、自分のパソコンで重い処理を回す作業です。僕の PC（メモリ16GB）では、動画の書き出し中に空きメモリが2GBほどになりました
- 迷ったら、**メモリ16GB・SSD 512GB以上**を目安にする。買ったあとに変えにくいことが多いからです
</Box>

動作条件は、2026年11月19日に Claude Code の公式ドキュメント（[Advanced setup](https://code.claude.com/docs/en/setup)）で確かめました。僕の PC の仕様は、同じ日にパソコン自身に表示させて確かめた値です。

| --- | --- |
| メーカー | 富士通（ノート PC） |

いわゆるゲーミング PC ではありません。

## AI の作業は、2種類に分かれる

AI を使う作業は、パソコンへの負担で2つに分けると考えやすくなります。

**1つめは、パソコンの外で重い処理が動くもの。** Claude や ChatGPT のチャット、Claude Code がそうです。考えるのはサーバーの側です。パソコンに必要なのは、ブラウザが動くことと、通信できること、ファイルを開けることくらいです。Claude Code の公式の動作条件は、メモリ4GB以上、x64 か ARM64 の CPU、通信環境です。Windows は 10 の 1809 以降が対象です。

**2つめは、自分のパソコンで重い処理を回すもの。** 動画の書き出し、音声の合成、画像の処理がそうです。ここで、パソコンの性能の差が出ます。

僕が Claude Code で作っている YouTube の動画づくりは、2つめにあたります。台本を書くところは軽いのに、映像を作るところで、急にパソコンが忙しくなるんです。

## 僕の PC で動画を作ったときに起きたこと

動画づくりの手順を書いた僕のメモに、こう残っています。

- 映像は、1コマずつ描いて、動画の形に書き出します。1コマに約0.3秒かかります
- 約1900コマの描画と書き出しは、4つの処理を並べて動かして、約3.5分でした
- そのとき、**空きメモリは2GBほどしかありませんでした**。それで、並列は4つまでにして、背景の素材を先に作って保存しておく形にしました
- 別の描画ライブラリを試したときは、全画面を1回塗るのに0.2秒、ぼかしに1秒かかって使えませんでした。ライブラリを変えたら、1〜6ミリ秒になりました。これは PC の性能ではなく、ソフトの選び方で変わった例です

つまり、メモリ16GBでも、動画を作る作業では余裕がなかったんです。メモリは、あとから増やせないノート PC が多いようです（機種ごとの仕様は確かめていません）。8GBで買っていたら、並列の数をもっと減らすか、作り方を変える必要があったと思います。ただし、僕は8GBの PC で試したわけではないので、「動かない」とまでは言えません。

声の合成にも時間がかかります。VOICEVOX で、90文ほどの台本の声を作ると、5分ほどかかりました（くわしくは「[VOICEVOX の使い方とクレジットの書き方](/blog/voicevox-how-to-credit/)」）。VOICEVOX の公式サイトには、対応 OS として Windows・Mac・Linux が書いてありました。必要なメモリの数字は見つかりませんでした（2026年11月19日に確認）。

## 選ぶときに見るところ

僕の経験から、見るところを順に並べます。

| 見るところ | 目安 | 理由 |
| --- | --- | --- |
| メモリ | 16GB以上 | あとから足せないことが多い。動画を作る作業で、16GBでも空きが2GBほどになった |
| SSD | 512GB以上 | 僕の PC は384GB使っていて、空きは約89GB。動画の作業フォルダだけで約7GBある |
| CPU | 僕は8コア | 4つの処理を並べて回せた。ほかのコア数は試していない |
| グラフィックボード | なくても動画は作れた | 僕の PC にはない。使うなら、この記事の範囲外 |
| OS | Windows 11 | 新しく買うなら 11 |

SSD は、容量が小さいと、動画の素材がすぐにたまります。僕の作業フォルダは、いま約7GBあります。ここに OS やほかのアプリが乗るので、256GBだと、僕の使い方では足りなくなりそうです。

## 逆に、気にしなくていいところ

- CPU の名前の細かい違いは、気にしなくていいです。僕は Core Ultra 5 で足りています。上位の型番との差は、試していないのでわかりません
- AI 専用の機能の有無も、気にしなくていいです。僕の作業（チャット、Claude Code、VOICEVOX、動画の書き出し）で、その機能を意識したことはありません
- グラフィックボードも、動画を作るだけなら、僕の PC でも書き出せています。画像を作る AI を自分のパソコンで動かしたいなど、使い方が決まってから考えれば足ります

## この記事で書けなかったこと

- ほかのメーカーや機種との比べ方は書けません。僕が使ったのは、いまの1台だけです
- Mac も書けません。僕は Windows でしか試していません
- バッテリーの持ちや重さは、大学に持ち歩くなら大事ですが、確かめていないので書きません。買うときは、メーカーの公式ページで確かめてください
- 値段は、機種ごとに大きく変わり、時期でも動くので、書いていません
