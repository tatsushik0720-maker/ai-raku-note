Claude Code を使い始めてから、困ったことがありました。前に伝えた好みや決まりを、毎回また伝え直さないといけないんです。「この言い回しは使わないで」「この形で書いて」と同じことを何度も言っていました。

そこで、Obsidian（オブシディアン）というメモアプリに、AI に読ませる「ルール帳」を作りました。いまの使い方はこうです。Claude Code が作業の前にメモを読みます。作業のあとには、記録を書き足してくれます。

<Box type="point" title="先に結論">
- Obsidian は、パソコンの中のフォルダにメモをふつうのテキスト（Markdown）で保存するアプリ。個人なら無料
- メモがただのファイルなので、Claude Code がそのまま読み書きできる。公式の CLI（コマンドで操作する道具）もある
- 僕の使い道は「AI との作業の記録」。文体のルール、デザインの好み、作ったスキルの一覧をためている
- 最初はフォルダを3つほど作るだけでいい。整理の仕方は、使いながら決めれば間に合う
</Box>

料金と CLI の情報は、2026年11月7日に Obsidian の公式サイトで確かめました。

## Obsidian とは

Obsidian は、メモを書いてリンクでつなげていくアプリです。いちばんの特徴は、保存場所です。メモはクラウドではなく、自分のパソコンのフォルダに `.md` のファイルとして入ります。

| 項目 | 内容 |
| --- | --- |
| 料金 | 個人・仕事とも無料（会社での利用には任意の有料ライセンスがある） |
| 保存場所 | 自分のパソコンのフォルダ（保管庫＝vault と呼ぶ） |
| 端末をまたぐ同期 | 有料の Obsidian Sync（年払いで月4ドル）か、ほかの方法を自分で用意 |
| 学生割引 | Sync と Publish が40%引き |

（料金は2026年11月7日時点）

僕はパソコンだけで使っているので、無料のままです。

## なぜ AI と相性がいいのか

メモがふつうのテキストファイルなので、Claude Code がそのまま開いて読めます。書き足すこともできます。専用のアプリの中に閉じ込められたメモだと、こうはいきません。

さらに、公式の CLI もあります。設定で有効にすると、コマンドで操作できます。たとえば「今日のデイリーノートを開く」「保管庫の中を検索する」「ノートに追記する」。Claude Code は、ふだんはこの CLI でメモを読み書きしています。ただし、使うときは Obsidian のアプリを起動しておく必要があります。

## 僕の保管庫の中身

保管庫は、いまこの4つのフォルダに分けています。

| フォルダ | 入れているもの |
| --- | --- |
| 文体ナレッジ | 文章の決まり。使わない言い回しのリストと、使える言い回しのリスト |
| AIとの付き合い方 | AI に伝えておきたい好み（ノートの見た目の好みなど） |
| Claude codeスキル一覧 | 自分で作った Claude Code のスキルの説明（いま16ページ） |
| メモ | どこにも入らないメモ |

入口として「ホーム」というノートを1枚置き、そこから各フォルダに飛べるようにしています。

### 文体ナレッジ：AI に毎回読ませるルール帳

AI の返事や、動画の台本で、「いかがでしたか」のような定番の言い回しが出ると、一気に安っぽくなります。そこで、使わない言い回しを理由と言い換えつきでリストにしました。いまは15件あります。

| 使わない言い回し | 言い換え |
| --- | --- |
| いかがでしたか | 自分の一言か、具体的な問いで終える |
| 〜と言えるでしょう（の連発） | 言い切るか、根拠を出す |
| 今回は〜を解説します | 結論・数字・問いから入る |

Claude Code には「日本語を書く前に、このリストを読む」という決まりを入れてあります。新しく気になる言い回しが出たら、その場でリストに足してもらいます。1回伝えたことが、次の作業からちゃんと守られるようになりました。

### スキル一覧：自動でたまる作業の記録

Claude Code には「スキル」という、作業の手順をまとめておく仕組みがあります。動画づくりやアプリづくりの手順を、スキルとして作ってきました。

スキルの中身を変えると、Obsidian のノートにも自動で書き写されるようにしています。いつ、何を足したかの履歴も残ります。手順を見直すときに、調べやすくなりました。

<Box type="memo" title="ノートの見た目もルールにした">
見返したときに一目でわかるよう、ノートの書き方も決めています。冒頭に要点の囲み、表は4列まで、流れは図で、といった決まりです。AI がノートを書くときも、この決まりに合わせてもらっています。
</Box>

## 始め方

1. Obsidian の公式サイトからアプリを入れる。アカウントの登録は要らない
2. 保管庫（メモを入れるフォルダ）を1つ作る
3. フォルダを3つほど作る。迷ったら「ルール」「記録」「メモ」で十分
4. AI に毎回伝えていることを、1枚のノートに書き出す
5. Claude Code に「作業の前にこのノートを読んで」と伝えておく

Claude Code の始め方は「[Claude Code の始め方【Windows】](/blog/claude-code-windows-start/)」にまとめています。

まずは、AI に何度も言っている決まりを3つ書き出すところからで大丈夫です。完璧に整理しなくても、使いにくいところが見えてからフォルダを分ければ間に合います。
