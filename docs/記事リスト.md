# 最初に書く記事20本

ジャンル：AI・作業効率化ツール（2026-11-05 決定）

## 方針

- **集客記事**で人を集め、**収益記事**に内部リンクでつなぐ。比率はおよそ 6：4
- 自分が実際にやったこと（Claude Code で動画・アプリを作る、Obsidian でメモを管理する、VOICEVOX でナレーションを作る）は、他の人が書けない強み。ここから先に書く
- 「おすすめ〇選」だけの記事は、大きなサイトに勝てない。比べるときも、自分で試した条件と結果を必ず入れる
- 案件（広告）があるかは、ASP に登録してから確かめる。下の「つなぐ広告の候補」は、まだ確かめていない予想
